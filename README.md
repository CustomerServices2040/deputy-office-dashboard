# شاشة المتابعة لمكتب نائب الرئيس

هذا المشروع مستقل في `CustomerServices2040/deputy-office-dashboard`. لا تُجرى أي كتابة أو إعادة نشر في مستودعات بوصلة المتعامل أو المشاريع الأخرى.

## التشغيل والحفظ المشترك

- تستضيف GitHub Pages الواجهة. السجل الحقيقي في `data/topics.enc.json` في **هذا المستودع فقط**.
- يدخل الموظف باسم المستخدم `deputyoffice` وكلمة مرور المكتب واسمه التعريفي. فك تشفير السجل يتم في المتصفح. كلمة المرور ومفتاح التشفير لا يُحفظان في ملفات المشروع أو التخزين المحلي.
- يتحدث العرض كل دقيقة وعند العودة للنافذة. القراءة تتم من الملف المشفّر على GitHub دون الحاجة إلى Firebase.
- زر **تعديل المحتوى** يطلب كلمة مرور التعديل ورمز GitHub مؤقتًا. تُستخدم كلمة مرور المكتب الحالية لفتح قفل التعديل وفك تشفير السجل؛ صلاحية الكتابة الفعلية تتحقق من GitHub.
- يجب إنشاء Fine-grained personal access token مع **Only select repositories → deputy-office-dashboard → Contents: Read and write**. لا يُرسل الرمز للمحادثة، ولا يُكتب في أي ملف. يبقى في ذاكرة جلسة الصفحة ويُزال عند قفل التعديل أو الخروج أو إعادة التحميل.
- الحفظ يقرأ أحدث نسخة من GitHub ثم يدمج الموضوع المطلوب فقط. اختلاف إصدار الموضوع نفسه يرفض التحديث القديم. تغير SHA بسبب تحديث موضوع آخر يعيد القراءة والدمج والمحاولة (ثلاث محاولات محدودة). لا يُستبدل سجل قديم كامل فوق تحديثات الزملاء.
- الموضوع الجديد والتحديثات تُشفّر بـ AES-256-GCM مع IV عشوائي لكل حفظ. اشتقاق المفتاح PBKDF2-SHA256 مع 310000 تكرار وsalt عشوائي. السجل العام لا يحتوي على أسماء أو توجيهات بنص مكشوف.
- الصفحة لا تستطيع منح صلاحية GitHub اعتمادًا على كلمة مرور فقط. المحرر يحتاج حسابًا مخولًا ورمزًا مقيّدًا بهذا المستودع؛ طريقة رمز الوصول هي ذات نمط الحفظ في بوصلة المتعامل، دون الاعتماد على خادمها أو تغيير إعداداته.
- اسم الموظف تعريفي ذاتي؛ مؤلف الـcommit في GitHub هو صاحب الرمز المستخدم. هذا ليس نظام إثبات هوية فردية إذا جرى تداول الحساب أو الرمز.

## الواجهة

مواضيع مرسال، البريد الإلكتروني، رسوم توزيع المديريات، البحث والتصفية، نافذة تفاصيل وتعديل، زر قفل التحرير، شاشة كاملة، وتصدير CSV. العرض للقراءة متاح بعد دخول المكتب، والإضافة والتعديل يحتاجان فتح القفل. لا تُنشر بيانات توضيحية بوصفها سجل عمل حقيقي.

## أيام العمل

يبدأ العد من اليوم التالي لتاريخ الوصول، مع استبعاد الجمعة والسبت. يظهر الموضوع المفتوح متأخرًا فقط عند **تجاوز** 14 يوم عمل. اليوم الرابع عشر نفسه ليس متأخرًا. المواضيع المنجزة والبريد الإلكتروني لا تدخل التأخير الآلي.

## النشر والاختبارات

Pages من `main` والمجلد `/ (root)` لهذا المستودع فقط. لا توجد إعادة توجيهات أو اتصالات بالخادم القديم، ولا حاجة إلى تثبيت مكتبات لبناء الواجهة.

```sh

```
