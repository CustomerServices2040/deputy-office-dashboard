# شاشة المتابعة لمكتب نائب الرئيس

مشروع مستقل في `CustomerServices2040/deputy-office-dashboard` فقط. الواجهة مفتوحة مباشرة لكل من لديه الرابط دون اسم مستخدم أو كلمة مرور للعرض.

## العرض والحفظ

السجل الحالي في `data/topics.json` قابل للقراءة العامة عبر GitHub. هذا مقصود بناءً على طلب إتاحة المحتوى لحاملي الرابط. لا يوجد ادعاء بأن سجل العرض العام مشفّر أو خاص. الملف المشفّر السابق محفوظ دون تغيير كنسخة تاريخية ولا يستخدمه التطبيق.

التعديل يتطلب زر **تعديل المحتوى**، واسم الموظف، وكلمة مرور التعديل، ورمز GitHub مقيّدًا بمستودع `deputy-office-dashboard` بصلاحية **Contents: Read and write**. تبقى صلاحية الكتابة الفعلية تحت تحكم GitHub؛ قفل كلمة المرور في الواجهة ليس بديلًا عن صلاحيات المستودع. الرمز يبقى في ذاكرة الجلسة فقط ويُزال بالقفل أو إعادة التحميل، ولا يوضع في أي ملف.

كل حفظ يقرأ أحدث سجل ويحدّث الموضوع المطلوب. اختلاف إصدار الموضوع نفسه يرفض التعديل القديم. تغير SHA بسبب تعديل آخر يعيد الدمج والمحاولة حتى ثلاث مرات. العرض يتحدث كل دقيقة وعند العودة للنافذة. الاسم المُدخل تعريفي ذاتي؛ صاحب رمز GitHub هو مؤلف الـcommit.

## الوظائف

مواضيع مرسال، البريد الإلكتروني، رسوم المديريات، البحث والتصفية، التعديل المحمي، الشاشة الكاملة مع عرض موسع بديل، وتصدير CSV. التأخير يبدأ عند تجاوز 14 يوم عمل، بعد استبعاد يوم الوصول والجمعة والسبت؛ المواضيع المنجزة والبريد الإلكتروني لا تدخل التأخير الآلي.

## النشر والاختبار

النشر من main وجذر هذا المستودع فقط. لا تعتمد المنصة على Firebase أو خادم بوصلة المتعامل. `npm test` يختبر العرض العام، وقفل الكتابة، وكلمة مرور خاطئة، وإصدارات المواضيع، وحدود أيام العمل.
