# شاشة المتابعة لمكتب نائب الرئيس

المستودع المستقل `CustomerServices2040/deputy-office-dashboard` فقط. لا تُجرى كتابة في أي مشروع آخر.

## العرض والحفظ

العرض محمي بكلمة مرور المكتب؛ يُفك تشفير `data/topics.enc.json` في المتصفح فقط. مفتاح التشفير وكلمات المرور ورمز GitHub لا تُحفظ في التخزين المحلي أو ملفات المشروع. التشفير AES-256-GCM مع IV عشوائي، واشتقاق مفتاح PBKDF2-SHA256 بعدد 310000 تكرار. كلمة مرور المكتب الحالية هي نفسها المتفق عليها سابقًا.

التعديل والاستيراد يتطلبان اسم المحرر ورمز GitHub فقط، دون كلمة مرور تعديل إضافية. كلمة مرور الدخول للعرض تبقى مستقلة. يجب أن يكون الرمز مقيّدًا بهذا المستودع بصلاحية Contents: Read and write. صلاحية الكتابة الفعلية يفرضها GitHub. الرمز يبقى في ذاكرة الجلسة فقط. يقرأ كل حفظ أحدث SHA ونسخة الموضوع، ويمنع الكتابة فوق تعديل زميل. تحديثات الدفعة تُحفظ في commit واحد مشفّر؛ رفض تكرار الأرقام قبل الكتابة. زر الخروج يزيل جلسة القراءة والتحرير من الذاكرة.

زر إضافة موضوع متاح بعد الدخول: إن لم تُفتح صلاحية التحرير، يعرض نافذة الرمز ثم يفتح نموذج الموضوع تلقائيًا بعد التحقق. ينطبق المسار نفسه على رفع ملف وإدخال نص. إلغاء نافذة الرمز يلغي الانتقال المنتظر، ولا يحفظ الرمز.

## استيراد المواضيع

ملفات Excel ‏XLSX/XLS/XLSM، Word ‏DOCX، PowerPoint ‏PPTX، PDF، صور PNG/JPG/JPEG/WEBP/BMP، إضافة إلى TXT/CSV/JSON. الحد الأقصى 20 ميجابايت للملف و500 موضوع و2 ميجابايت للنص المستخرج. يلزم حفظ ملفات DOC/PPT القديمة بصيغ DOCX/PPTX أولًا. لا تُرسل محتويات الملفات إلى خدمة ذكاء اصطناعي خارجية. التحليل محلي قائم على الحقول والفواصل، وليس استنتاجًا للمعلومات غير المذكورة.

- CSV: صف أول لعناوين الحقول. تدعم الفواصل والفواصل المنقوطة وعلامات الاقتباس والنص متعدد الأسطر.
- JSON: مصفوفة مواضيع أو كائن يحوي topics.
- TXT/النص: `رقم الموضوع: ...` ثم `اسم الموضوع: ...` و`آخر التوجيهات: ...` و`الموظف المسؤول: ...` و`تاريخ الوصول: YYYY-MM-DD` و`المديرية المختصة: ...`. افصل المواضيع بسطر فارغ. الأسطر المرقمة تُفصل كمواضيع وتُترك الحقول الناقصة للمراجعة.
- زر تحليل يعرض جدولًا قابلًا للتصحيح. لا حفظ قبل اعتماد المستخدم، ولا حذف أو استبدال جماعي للسجل. يمنع الحفظ إن كانت الحقول ناقصة أو الرقم مكررًا أو التاريخ غير صالح/مستقبلي.

## استعادة البيانات

عند هذه المراجعة: سجل GitHub العام لا يحوي مواضيع، والسجل المشفّر السابق لا يحوي مواضيع، وجدول office_topics في النسخة الأصلية لا يحوي صفوفًا. لذلك لم تُنشأ بيانات عمل بديلة أو تُحوّل الأمثلة إلى سجلات حقيقية. نسخة السجل العام الفارغ القديمة موجودة في تاريخ GitHub فقط. أي بيانات أُدخلت ولم تُحفظ تتطلب نسخة من صاحبها لاستعادتها.

## الوظائف والتحقق

مرسال، البريد، الرسوم، البحث، الفلاتر، تعديل محمي، شاشة كاملة وعرض موسع بديل، وتصدير CSV. التأخير بعد تجاوز 14 يوم عمل، دون يوم الوصول والجمعة والسبت. لا Firebase ولا اتصال بخادم بوصلة المتعامل.

`npm test` يتحقق من الاستيراد والتواريخ والحقول والتكرار وكلمة المرور والتشفير وحفظ الدفعة. تستخدم اختبارات الكتابة GitHub محاكاة ورموزًا اصطناعية؛ لا تُنشئ بيانات عمل حقيقية. النشر من main وجذر المستودع فقط.

## الإضافات المحددة

- حذف موضوع بعد تأكيد، بصلاحية التحرير القائمة. يحتفظ السجل المشفّر بعلامة الحذف ونسخة الموضوع لاسترجاع إداري لاحق، ويُستبعد من العرض والإحصائيات. لا توجد واجهة استعادة جديدة.
- عمود عدد أيام العمل وفلتر عدد مطابق في مرسال والمتأخرات، مثل 6؛ البريد لا يملك تاريخ وصول في مخططه الأصلي لذلك لا يُخترع عدد أيام له.
- استخراج الملفات محلي في المتصفح. تُحمّل مكتبات القراءة وملفات لغة OCR عند أول استخدام من CDN؛ محتوى الملفات لا يُرسل إليها. قد تمنع شبكة المؤسسة تحميلها، وعندها يظهر خطأ واضح. PDF حتى 50 صفحة، والممسوح ضوئيًا حتى 10 صفحات، وPowerPoint حتى 100 شريحة. تُراجع نتائج OCR قبل اعتمادها ولا تُعتبر مضمونة الدقة.
- لا تغيير في كلمة مرور العرض أو آلية صلاحية GitHub أو باقي تصميم المنصة.
